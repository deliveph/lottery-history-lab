## 易经八卦模式

项目本地新增 `iching` 模式：

- 年月日计算上卦。
- 年月日加下一期号计算下卦和动爻。
- 使用八卦序数、五行尾数和变爻轮转形成抽样权重。
- 平衡5组之间的号码使用次数。
- 相同游戏、目标日期和期号可重复得到相同结果。
- 这是自定义娱乐映射，不是传统术数断语或统计模型。

CLI 示例：

```powershell
python -m lottery_lab generate --offline --mode iching `
  --dlt-date 2026-08-31 --ssq-date 2026-09-01
```
