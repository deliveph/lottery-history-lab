## 方法讨论

用户询问 GitHub 或网上是否存在提高中奖率的算法、模型。形成的关键结论：

- 在公平独立摇奖前提下，历史开奖不能预测下一期。
- 蒙特卡洛、遗传算法等可用于赔率、方差或覆盖设计，但不能预测独立随机开奖。
- 多注低重叠可以改变小奖覆盖和方差，不提高每注头奖概率。
- 避开热门组合可能减少中浮动奖时的平分人数，但不改变开奖概率。
