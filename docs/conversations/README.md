本目录按北京时间逐日记录 `lottery-history-lab` 的用户需求、数据快照、选号方案、
开奖结果和代码决策。它是聊天上下文被压缩后的项目状态入口，不替代官方开奖数据。

## 使用方式

1. 先阅读本页“当前状态”。
2. 再阅读日期最新的日志。
3. 如需核对开奖或生成下一期号码，先联网更新数据。
4. 当天完成工作后，追加当天日志并更新本索引。

## 统一术语

- 命中数 `a+b`：大乐透表示前区命中数＋后区命中数，双色球表示红球命中数＋蓝球命中数。
- 低重叠：在固定注数内减少不同注之间的号码重复，优化覆盖范围，不改变每注概率。
- 反热门：尝试避开常见人工选号偏好，可能降低浮动奖平分概率，不提高开奖概率。
- 起卦：自定义、确定性的娱乐映射，不是统计模型或传统术数断语。
